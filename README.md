# 🎮 Hangman Game

## 📌 About the Project

Hangman Game is a simple text-based word guessing game developed using Python. The player must guess a hidden word one letter at a time.

## 🎯 Features

* Contains 5 predefined words.
* Allows 6 incorrect guesses.
* Displays correctly guessed letters.
* Checks user input.
* Shows win or lose messages.

## 🛠️ Technologies Used

* Python
* Random module
* While loop
* If-else statements
* Strings and Lists

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python hangman.py
```

## 🎲 How to Play

1. Run the program.
2. Guess one letter at a time.
3. Find the hidden word before using all 6 incorrect guesses.
4. Win by guessing all the letters correctly!
